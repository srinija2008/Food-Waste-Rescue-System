# Syllabus mapping

- Unit I (OOP): User abstract class, Donor and Volunteer inheritance, FoodDonation class, encapsulation, constructors, overriding, Reportable interface, packages, static/final members.
- Unit II (Exceptions and threads): FoodRescueException, try/catch/finally, ScheduledExecutorService deadline monitor, synchronized service methods, String and StringBuffer can be extended in report/log features.
- Unit III (Collections and streams): ArrayList, LinkedList, HashSet, HashMap, TreeSet, TreeMap; FileReader/FileWriter, FileInputStream/FileOutputStream, serialization, report reading/writing.
- Unit IV (GUI): JFrame, JPanel, JTabbedPane, JLabel, JTextField, JButton, JTable, JScrollPane, BorderLayout, GridLayout, FlowLayout, event listeners.
- Unit V (JDBC): DriverManager, Connection, PreparedStatement, CallableStatement, ResultSet, CRUD operations.
